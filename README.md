# 🏎️ F1 Telemetry Explorer

**F1 Telemetry Explorer** — это веб-приложение для анализа телеметрии «Формулы-1», сравнения показателей пилотов и автоматического поиска аномалий (резких торможений, вылетов с трассы, пит-стопов) на основе открытого API [OpenF1](https://openf1.org/).

## Основные возможности

*   **Сравнение телеметрии:** Наложение графиков скорости нескольких пилотов друг на друга (по времени сессии или по конкретному кругу).
*   **Автоматическая детекция аномалий:** Гибридный алгоритм (Z-score + анализ производной) находит резкие падения скорости и выделяет их красными зонами на графике.
*   **Результаты сессий:** 
    *   Таблица результатов сессии (позиции, очки, лучшие круги).
    *   Визуализация подиума.
    *   Стратегии использования шин (Soft, Medium, Hard).
    *   Погодные условия (температура воздуха и трассы).
    *   Положение в чемпионате пилотов и Кубке конструкторов.
*   **Современный UI/UX:** Переключение между темной и светлой темами, адаптивная верстка в стиле трансляций F1.

## Технологический стек

**Frontend:**
*   React (TypeScript)
*   Vite
*   Chart.js (библиотека для графиков) + `chartjs-plugin-annotation` (для отрисовки аномалий)
*   React Router DOM

**Backend:**
*   Python 3.12
*   FastAPI (асинхронный веб-фреймворк)
*   Pandas (обработка данных)
*   Requests (взаимодействие с OpenF1 API)

**Инфраструктура:**
*   Docker & Docker Compose
